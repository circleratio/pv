# 概要
PDFをプレゼン用に表示するツール。

# 実行形式
pv [PDFファイル]

- PDFファイルが指定されずに起動された場合は、ファイル選択ダイアログは表示せず、PDFを読み込まない空白のウィンドウを表示する（ファイルを開く操作は「ファイル履歴」節を参照）。

# 処理内容

## ウィンドウ
- PDFをメインウィンドウに表示する。メニューバー、サイドバーは持たない。
- 起動時は通常ウィンドウ（タイトルバーあり、リサイズ可・最大化可）として表示する。フルスクリーンは指定しない。
- PDFページはウィンドウに収まるようにアスペクト比を保って拡大縮小して表示する。
- PDFを開いた際（起動時の引数指定、「ファイルを開く」、履歴からの再オープンのいずれも）は、余白ができないよう、開いたPDFの1ページ目のアスペクト比に合わせてウィンドウをリサイズする。リサイズ後のウィンドウ面積は、リサイズ前のウィンドウ面積をなるべく保つように決定する。ウィンドウが最大化されている場合は、最大化を解除してからリサイズする。ただし全画面モード中は、PDFを開いてもこのリサイズは行わず全画面モードを維持する。
- 全画面モードと通常モードを右クリックメニューからトグルできる（詳細は「ファイル履歴」節を参照）。
- 全画面モード中にEscキーを押した場合は、まず全画面モードを解除する（アプリケーションは終了しない）。全画面モードでない状態でEscキーを押すとアプリケーションを終了する。

## ページ送り
- 矢印キー、マウスのホイールでページを前後に進めることができる。
  - 矢印キー：→・↓＝次ページ、←・↑＝前ページ。
  - マウスホイール下回転＝次ページ、上回転＝前ページ。
- スペースでページを進める。
- BSでページを戻す。
- 最初のページで前に戻る操作、最後のページで次に進む操作をした場合は何もしない（端で停止し、ループしない）。
- 特定ページへのジャンプ機能（ページ番号入力等）は設けない。前後移動のみとする。

## ファイル履歴
- マウスの右ボタンをクリックすると、メニューが表示される（右ボタンには他の機能を割り当てない）。メニューには以下を含む。
  - 「ファイルを開く」：ファイル選択ダイアログを表示し、選択したPDFファイルを開く。
  - 全画面モードと通常モードのトグル：選択すると現在のモードを切り替える。項目の表示文言は現在のモードに応じて変える（例: 通常モード中は「全画面にする」、全画面モード中は「全画面を解除」）。
  - ファイル履歴の一覧：選択するとそのPDFファイルを開く。
- ウィンドウ内へPDFファイルをドラッグ＆ドロップすると、そのファイルを開く。複数ファイルが同時にドロップされた場合は先頭の1件のみを開く。
- PDFファイルを開くたびに（起動時の引数指定、「ファイルを開く」によるダイアログ選択、履歴からの再オープン、ドラッグ＆ドロップのいずれも）、そのファイルを履歴に記録する。履歴はローカルに保存し、アプリケーションを再起動しても保持する。
- 履歴は最大10件までとする。10件を超えて記録される場合は、最も古い履歴から削除する。
- 既に履歴にあるファイルを再度開いた場合は、履歴に重複して追加せず、そのファイルの履歴を最新（先頭）に繰り上げる。

## レーザーポインター
- マウスの左ボタンを押している間、レーザーポインターモードになる（左ボタンを離すと通常モードに戻る）。
- レーザーポインターモード中、クリックした場所には一時的な点を、ドラッグした場合は移動前後のマウス位置を結ぶオレンジの線で軌跡を強調表示する（丸を個別に描画するのではなく、線でつなぐ）。
- 強調表示（線の太さ・クリック時の点の直径）は固定px値ではなく、PDF表示領域（ウィンドウサイズ）に対する相対値とする。表示領域の短辺の約1.4%を太さ・直径とする（例: 短辺768pxのウィンドウで太さ・直径約11px相当）。
- 強調表示は表示されてから1〜2秒程度かけて自動的にフェードアウトして消える。
- レーザーポインターモード中も、矢印キー・ホイール等によるページ送り操作は有効とする。

# 技術要件
- Tauri
- フロントエンド: Vanilla JS + HTML/CSS（フレームワークは使用しない）
- PDFレンダリング: pdf.js（フロントエンド側でCanvas等に描画する）
- ファイル選択ダイアログ: tauri-plugin-dialog を使用する
- 対応OS: Windows / macOS / Linux（Tauriのクロスプラットフォーム対応範囲とする）

# 非機能要件
- 特に数値目標は定めない。pdf.jsの一般的な性能を前提とし、通常のプレゼン資料規模のPDFで問題なく動作すればよいものとする。

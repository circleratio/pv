# 概要
PDFをプレゼン用に表示するツール。

# 実行形式
pv [PDFファイル]

- PDFファイルが指定されずに起動された場合は、ファイル選択ダイアログを表示し、ユーザーにPDFファイルを選択させる。

# 処理内容

## ウィンドウ
- PDFをメインウィンドウに表示する。メニューバー、サイドバーは持たない。
- 起動時は通常ウィンドウ（タイトルバーあり、リサイズ可・最大化可）として表示する。フルスクリーンは指定しない。
- PDFページはウィンドウに収まるようにアスペクト比を保って拡大縮小して表示する。
- Escキーでアプリケーションを終了する。

## ページ送り
- 矢印キー、マウスのホイールでページを前後に進めることができる。
  - 矢印キー：→・↓＝次ページ、←・↑＝前ページ。
  - マウスホイール下回転＝次ページ、上回転＝前ページ。
- スペースでページを進める。
- BSでページを戻す。
- 最初のページで前に戻る操作、最後のページで次に進む操作をした場合は何もしない（端で停止し、ループしない）。
- 特定ページへのジャンプ機能（ページ番号入力等）は設けない。前後移動のみとする。
- PDFファイルのドラッグ＆ドロップによるオープンには対応しない（コマンドライン引数指定のみ）。

## レーザーポインター
- マウスの左ボタンを押している間、レーザーポインターモードになる（左ボタンを離すと通常モードに戻る）。
- レーザーポインターモード中、クリックした場所には一時的な点を、ドラッグした場合は移動前後のマウス位置を結ぶオレンジの線で軌跡を強調表示する（丸を個別に描画するのではなく、線でつなぐ）。
- 強調表示（線の太さ・クリック時の点の直径）は固定px値ではなく、PDF表示領域（ウィンドウサイズ）に対する相対値とする。表示領域の短辺の約1.4%を太さ・直径とする（例: 短辺768pxのウィンドウで太さ・直径約11px相当）。
- 強調表示は表示されてから1〜2秒程度かけて自動的にフェードアウトして消える。
- レーザーポインターモード中も、矢印キー・ホイール等によるページ送り操作は有効とする。

# 技術要件
- Tauri
- フロントエンド: Vanilla JS + HTML/CSS（フレームワークは使用しない）
- PDFレンダリング: pdf.js（フロントエンド側でCanvas等に描画する）
- ファイル選択ダイアログ: tauri-plugin-dialog を使用する
- 対応OS: Windows / macOS / Linux（Tauriのクロスプラットフォーム対応範囲とする）

# 非機能要件
- 特に数値目標は定めない。pdf.jsの一般的な性能を前提とし、通常のプレゼン資料規模のPDFで問題なく動作すればよいものとする。

# 概要
PDFをプレゼン用に表示するツール。

# 実行形式
pv [PDFファイル]

- PDFファイルが指定されずに起動された場合は、ファイル選択ダイアログは表示せず、PDFを読み込まない空白のウィンドウを表示する（ファイルを開く操作は「ファイル履歴」節を参照）。
- 起動時引数のPDFファイルパスが相対パスで指定された場合は、起動時のカレントディレクトリを基準に絶対パスへ変換したうえで扱う（シンボリックリンクの解決は行わない）。以降、ファイル履歴への記録を含め、この絶対パスを用いる。
- 「ファイルを開く」ダイアログおよびドラッグ＆ドロップで取得するファイルパスは、OS/Tauri側から絶対パスとして渡される前提とし、アプリケーション側で追加の絶対パス変換は行わない（絶対パスへの変換が必要となるのは起動時引数の場合のみ）。

# 処理内容

## ウィンドウ
- PDFをメインウィンドウに表示する。メニューバー、サイドバーは持たない。
- 起動時は通常ウィンドウ（タイトルバーあり、リサイズ可・最大化可）として表示する。フルスクリーンは指定しない。
- PDFページはウィンドウに収まるようにアスペクト比を保って拡大縮小して表示する。
- PDFを開いた際（起動時の引数指定、「ファイルを開く」、履歴からの再オープンのいずれも）は、余白ができないよう、開いたPDFの1ページ目のアスペクト比に合わせてウィンドウをリサイズする。リサイズ後のウィンドウ面積は、リサイズ前のウィンドウ面積をなるべく保つように決定する。ウィンドウが最大化されている場合は、最大化を解除してからリサイズする。この場合の「リサイズ前のウィンドウ面積」は、最大化時の面積ではなく、最大化を解除した直後（元の通常サイズに戻った状態）の面積を指す。ただし全画面モード中は、PDFを開いてもこのリサイズは行わず全画面モードを維持する。PDF内のページごとにアスペクト比が異なる場合でも、ウィンドウのリサイズは1ページ目のアスペクト比のみを基準とする。2ページ目以降で1ページ目とアスペクト比が異なるページを表示する際に生じる余白は許容する。
- アスペクト比維持・面積維持の計算結果、ウィンドウサイズが画面（現在表示しているディスプレイ）を超える場合は、アスペクト比を保ったまま画面に収まる最大サイズにクランプする。
- 全画面モード中に開いたPDFについては、リサイズを行わず全画面モードを維持したままとする（前述のとおり）。その後ユーザーが全画面モードを解除した場合も、開いたPDFのアスペクト比に基づくリサイズは行わず、全画面モードに入る前の通常ウィンドウサイズにそのまま戻る（解除を契機としたリサイズの後追い適用は行わない）。
- 全画面モードと通常モードを右クリックメニューからトグルできる（詳細は「ファイル履歴」節を参照）。
- 全画面モード中にEscキーを押した場合は、まず全画面モードを解除する（アプリケーションは終了しない）。全画面モードでない状態でEscキーを押すとアプリケーションを終了する。

## ページ送り
- 矢印キー、マウスのホイールでページを前後に進めることができる。
  - 矢印キー：→・↓＝次ページ、←・↑＝前ページ。
  - マウスホイール下回転＝次ページ、上回転＝前ページ。
- スペースでページを進める。
- BSでページを戻す。
- 最初のページで前に戻る操作、最後のページで次に進む操作をした場合は何もしない（端で停止し、ループしない）。
- 特定ページへのジャンプ機能（ページ番号入力等）は設けない。前後移動のみとする。ただし、「スライド一覧表示」節のスライド一覧からダブルクリックでスライドを選択する操作はこの制約の対象外とする（キー入力等によるページ番号指定ジャンプを禁止する趣旨であり、一覧表示からの選択操作とは矛盾しない）。

## ファイル履歴
- マウスの右ボタンをクリックすると、メニューが表示される（右ボタンには他の機能を割り当てない）。メニューには以下を含む。
  - 「ファイルを開く」：ファイル選択ダイアログを表示し、選択したPDFファイルを開く。ダイアログはPDFファイルのみを選択可能なフィルタを設定する。
  - 全画面モードと通常モードのトグル：選択すると現在のモードを切り替える。項目の表示文言は現在のモードに応じて変える（例: 通常モード中は「全画面にする」、全画面モード中は「全画面を解除」）。
  - ファイル履歴の一覧：選択するとそのPDFファイルを開く。
- ウィンドウ内へPDFファイルをドラッグ＆ドロップすると、そのファイルを開く。複数ファイルが同時にドロップされた場合は先頭の1件のみを開く（「先頭」の判定基準はOS/Tauriがドロップイベントとして渡すファイル順序に従い、アプリケーション仕様としては規定しない）。ドロップされた先頭の1件がPDF以外のファイルであった場合は、エラー表示等は行わず単に無視する（何も開かない。2件目以降にPDFファイルが含まれていても見ない）。
- PDFファイルを開くたびに（起動時の引数指定、「ファイルを開く」によるダイアログ選択、履歴からの再オープン、ドラッグ＆ドロップのいずれも）、そのファイルを履歴に記録する。履歴はローカルに保存し、アプリケーションを再起動しても保持する。
- 履歴は最大10件までとする。10件を超えて記録される場合は、最も古い履歴から削除する。
- 既に履歴にあるファイルを再度開いた場合は、履歴に重複して追加せず、そのファイルの履歴を最新（先頭）に繰り上げる。同一ファイルかどうかの判定は、記録されているパス文字列との完全一致とする（大文字小文字・シンボリックリンク等の正規化は行わない）。
- 履歴から選択したファイルを開こうとして失敗した場合（ファイルが移動・削除されている等）は、そのエントリを履歴から削除する。
- 右クリックメニュー表示中にEscキーを押した場合は、メニューを閉じるのみとする（全画面モードの解除・スライド一覧表示モードの終了・アプリケーションの終了のいずれも行わない）。この判定は「ウィンドウ」節・「スライド一覧表示」節に記載のEscキーの挙動より優先する。

## スライド一覧表示
- マウスの右ボタンメニューに、スライド一覧表示モードと通常表示モードを切り替えるトグル項目を追加する。項目の表示文言は現在のモードに応じて変える（例: 通常表示中は「スライド一覧表示にする」、スライド一覧表示中は「スライド一覧表示を解除」）。
- PDFが読み込まれていない状態（空白のウィンドウ）では、スライド一覧表示モードには入れない。この間、メニュー項目は選択できない状態（無効表示）で表示する。
- スライド一覧表示モードでは、開いているPDFの全スライドについて、スライド番号とサムネイル画像のセットを縦横に並べたグリッドとして表示する。
- グリッド内のスライドをシングルクリックすると、そのスライドをカレントスライド（現在の表示位置）にする。カレントスライドに対応するタイルは常にハイライト表示する。この操作だけではスライド一覧表示モードは終了しない。
- グリッド内のスライドをダブルクリックすると、そのスライドをカレントスライドにしたうえで通常表示（1スライド表示）に遷移し、スライド一覧表示モードを終了する。
- スライド一覧表示モードを終了して通常表示に戻る際（ダブルクリックによる終了・Escキー・右クリックメニューからの解除のいずれの場合も）は、その時点のカレントスライドが表示される。
- スライド一覧表示モード中は、矢印キー・スペース・BS・マウスホイールによるページ送り操作は無効とする。
- スライド一覧表示モード中にEscキーを押した場合は、カレントスライドを表示した通常表示モードに戻る（アプリケーションは終了しない）。全画面モードとスライド一覧表示モードの両方が有効な状態でEscキーを押した場合は、まずスライド一覧表示モードを解除する。
- スライド一覧表示モード中も、右クリックメニュー（「ファイルを開く」・全画面トグル・ファイル履歴・本トグル自体）は引き続き利用できる。
- スライド一覧表示モード中に新しいPDFファイルを開いた場合（「ファイルを開く」・履歴からの再オープン・ドラッグ＆ドロップのいずれも）は、スライド一覧表示モードを終了し、開いたPDFの1ページ目を通常表示（1スライド表示）する。この場合も「ウィンドウ」節のリサイズ処理（1ページ目のアスペクト比に合わせたウィンドウリサイズ）を行う。ただし全画面モード中は、「ウィンドウ」節の全画面時リサイズ抑制ルールを優先し、リサイズは行わず全画面モードを維持する（スライド一覧表示モードのみ終了する）。

## レーザーポインター
- マウスの左ボタンを押している間、レーザーポインターモードになる（左ボタンを離すと通常モードに戻る）。ただし、プレゼン画面（PDF表示領域）を直接左クリックした場合に限る。右クリックメニュー等のUI要素上での左クリックはレーザーポインターモードの対象外とする。
- スライド一覧表示モード中は、レーザーポインターは無効とする（グリッド内のタイルへの左クリックはスライド一覧表示節の選択操作としてのみ機能し、レーザーポインターは発生しない）。
- レーザーポインターモード中、クリックした場所には一時的な点を、ドラッグした場合は移動前後のマウス位置を結ぶオレンジの線で軌跡を強調表示する（丸を個別に描画するのではなく、線でつなぐ）。
- 強調表示（線の太さ・クリック時の点の直径）は固定px値ではなく、PDF表示領域（ウィンドウサイズ）に対する相対値とする。表示領域の短辺の約1.4%を太さ・直径とする（例: 短辺768pxのウィンドウで太さ・直径約11px相当）。
- 強調表示は表示されてから約1秒かけて自動的にフェードアウトして消える。
- レーザーポインターモード中も、矢印キー・ホイール等によるページ送り操作は有効とする。

# 技術要件
- Tauri
- フロントエンド: Vanilla JS + HTML/CSS（フレームワークは使用しない）
- PDFレンダリング: pdf.js（フロントエンド側でCanvas等に描画する）
- ファイル選択ダイアログ: tauri-plugin-dialog を使用する
- 対応OS: Windows / macOS / Linux（Tauriのクロスプラットフォーム対応範囲とする）

# 非機能要件
- 特に数値目標は定めない。pdf.jsの一般的な性能を前提とし、通常のプレゼン資料規模のPDFで問題なく動作すればよいものとする。
